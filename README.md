# Uber-Data-Analysis-Dashboard
Project Title: Uber-Data-Analysis-Dashboard

Short Discription:
This Power BI project presents a comprehensive analysis of Uber ride data through multiple interactive dashboards. The report provides insights into ride performance, revenue trends, customer behavior, vehicle distribution, and location-based analytics. It helps in understanding key business metrics such as bookings, cancellations, revenue generation, and customer preferences.

Tools & Technologies:
Power BI – Data visualization and dashboard creation,
DAX (Data Analysis Expressions) – Calculated measures and KPIs,
Power Query – Data cleaning and transformation,
Data Modeling – Relationships between multiple datasets.

Key Features:
Interactive dashboards with slicers (Month/Quarter, Pickup/Drop locations),
KPI cards for Bookings, Revenue, Distance, and Ratings,
Drill-down analysis across time (monthly & quarterly trends),
Vehicle-wise and customer-wise performance insights,
Dynamic maps to visualize pickup & drop locations,
Distance calculation between selected locations,
Clean and user-friendly UI for better data storytelling.

Dashboard Breakdown:

1. Overview Dashboard:
Displays high-level KPIs like total bookings, revenue, distance, and average distance,
Monthly trends of completed rides and revenue,
Ride status distribution (Completed, Cancelled, Incomplete),
Customer and driver ratings,
Top pickup and drop locations.

2. Vehicle Dashboard:
Vehicle-wise performance analysis (Auto, Bike, Go Mini, Sedan, etc.),
Total bookings, completed rides, and cancellations per vehicle,
Revenue contribution by each vehicle type,
Percentage contribution visualization.

3. Revenue Dashboard:
Revenue breakdown by vehicle type and customers,
Top customers contributing to revenue,
Payment method analysis (UPI, Cash, Wallet, Cards),
Monthly revenue trends.

4. Rider Dashboard:
Customer growth trends (monthly & quarterly),
Customer distribution based on payment methods,
Ride cancellation analysis with reasons,
Customer demand insights.

5. Location Dashboard:
Interactive maps showing pickup and drop locations,
Slicers to filter locations dynamically,
Card displaying distance between selected pickup and drop points,
Helps analyze geographical ride patterns.
